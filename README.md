# Terraform Learning

This repository documents my hands-on Terraform learning progression

It contains exercises and projects completed while working the Terraform LM Academy course. 

## What I have covered

- Terraform providers and resources
- Variables, locals and expressions
- Data sources
- 'count' and 'for_each'
- VPC, subnet and EC2 configuration
- IAM users, roles and policies
- Reading configuration from YAML
- IAM role trust policies
- Public Terraform modules

## Projects

### Public Modules
Using public Terraform Registry modules to build AWS infrastructure, starting with the AWS VPC module.

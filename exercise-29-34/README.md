# Exercises 29-34

This folder contains Terraform configuration developed progressively through exercises 29 - 34. 

## Progression
- Exercise 29 - Create EC2 instances from a list variable
- Exercise 30 - Extend AMI configuration for NGINX
- Exercise 31 - Add validation to list variables
- Exercise 32 - Create EC2 instnaces from a map using 'for_each'
- Exercise 33 - Add validation to map variables
- Exercise 34 - Pass subnet configuration using maps and named subnets

The configuration was refactored across these exercises rather than creating a new project for each exercise.
